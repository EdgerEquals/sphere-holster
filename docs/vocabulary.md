# Vocabulary

Adopted terminology for the Holster / stratified-sphere review loop and apparatus.

## Process language (SpaceX-style)

Names the review loop's operations. Not physics.

| Term | Meaning |
|------|---------|
| **scrub** | A round cancelled before firing. |
| **hold** | A round paused mid-flight. |
| **abort** | A round stopped after firing. |
| **anomaly** | A ping that dies or misbehaves mid-run. |
| **nominal** | A round that completes cleanly. |
| **go/no-go** | The checklist decision that starts or blocks a round. |
| **mission patch** | The round's name. |

## Physics language

Names the apparatus and its behavior. Unchanged project terms.

| Term | Meaning |
|------|---------|
| **drive** | The input excitation applied to the sphere. |
| **threshold** | The drive or response level at which a named transition occurs. |
| **amplitude** | Magnitude of the driven or observed response. |
| **resonance** | Peak response when drive frequency matches a mode of the system. |
| **sphere / holster** | Interchangeable names for the program/code and the hardware fixture. |
| **stratified core** | The layered inner structure of the sphere. |
| **Keely sphere** | Historical / program name for the stratified sphere apparatus. |
| **ring-down** | Decay of amplitude after drive is removed. |
| **ring-up** | Build-up of amplitude after drive is applied. |
| **detune** | Offset of drive frequency from a resonance. |
| **tune** | Being on resonance; the opposite of detune. |
| **Q** | Quality factor; sharpness of a resonance (energy stored vs energy lost per cycle). |
| **standing wave** | A spatial mode with fixed nodes and antinodes under continuous drive. |

### Physics usage examples

- Ring-down: "After drive-off, ring-down τ fitted to 12 ms."
- Ring-up: "Ring-up to steady amplitude took ~3 Q-cycles."
- Detune: "Sweep held at +2% detune from the acoustic peak."
- Tune: "A tuned core draws minimal transmitter current."
- Q: "Loaded Q dropped from ~800 to ~200 at 4 W."
- Standing wave: "The standing wave antinode sat at the stratified-core boundary."

## The split

Process terms name the loop's operations. Physics terms name the apparatus and its behavior. Do not mix them — e.g. no "booster" or "payload" for the sphere.

## Correct usage

- Process: "Round 6 scrubbed before launch."
- Physics: "The 4 W amplitude sweep crossed threshold."
